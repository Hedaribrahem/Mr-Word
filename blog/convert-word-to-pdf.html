تحويل ملف Word إلى PDF والعكس بدون برامج إضافية

25 أكتوبر 2026 · 2 دقائق قراءة

تحتاج غالباً إلى PDF عند إرسال مستند رسمي أو سيرة ذاتية، لأن الشكل لا يتغير على جهاز القارئ. وهذه الطرق تعمل من Word نفسه دون برامج إضافية.

من Word إلى PDF

  1. افتح المستند، ثم File (ملف) ← Save As (حفظ باسم).
  2. اختر مكان الحفظ، ومن قائمة نوع الملف اختر PDF.
  3. اضغط Save.
بديل: File ← Export ← Create PDF/XPS Document. وفيه زر Options لتحديد صفحات معينة فقط.

على جهاز Mac: File ← Save As ثم اختر PDF من File Format. وفي Word على الويب ابحث عن خيار التنزيل أو التصدير بصيغة PDF من قائمة File.

نصائح للحفاظ على الشكل

  • راجع المستند قبل الحفظ: الفهارس وأرقام الصفحات والصفحات الفارغة.
  • إن كان الملف كبيراً بسبب الصور، جرّب Minimum size من خيار Optimize for عند الحفظ، وقارن الجودة.
  • افتح ملف PDF بعد حفظه وراجعه، خاصة الجداول والروابط.

من PDF إلى Word

  1. افتح Word واختر File ← Open، ثم اختر ملف PDF.
  2. سيخبرك Word أنه سيحوّل الملف إلى مستند قابل للتعديل، فوافق.
  3. راجع النتيجة، فقد يتغير التنسيق قليلاً خاصة في الجداول والأعمدة والخطوط الخاصة.
يعمل هذا جيداً مع ملفات PDF النصية، أما الملفات الممسوحة ضوئياً (صور) فلا تتحول إلى نص قابل للتعديل بهذه الطريقة.

تنبيه للخصوصية

مواقع التحويل المجانية على الإنترنت تعني رفع ملفك إلى خادم لا تعرف من يديره. تجنبها مع المستندات الحساسة، واستخدم Word نفسه كلما أمكن.

وإن كان عندك ملف PDF وتريد تحويله إلى مستند Word مرتب وجاهز للتعديل، اطلب خدمتنا وأرسل لنا الملف.
